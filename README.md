# BananaHunt

BananaHunt is an endless vertical runner game developed in Unity, where players control a character that must climb higher while avoiding obstacles and collecting bananas. The goal is to survive as long as possible, achieving the highest score by collecting bananas and avoiding obstacles along the way.


## Features
- Endless vertical runner gameplay.
- Collect bananas to increase score.
- Avoid obstacles and traps.
- Multiple levels with increasing difficulty.
- Smooth character movement and controls.
- Beautiful and vibrant environment.
## Installation

### Requirements:
- Unity 2022.3.47f1 (or later).
- C# programming language.
- Unity's standard assets for character and obstacle setup.

### Steps to run the project:

1. Clone the repository to your local machine:
   ```bash
   git clone https://github.com/namruthagude/DinoMover.git
   ```
3. Open the project in Unity:
  - Launch Unity Hub and click on "Add".
  - Select the directory where the project was cloned.
3. Ensure that the Unity version you are using is 2022.3.47f1 or later.
4. Hit the play button in the Unity Editor to start playing!

## Gameplay

- The game starts with the character at the bottom of the screen, with the objective being to climb higher and higher.
- The character must avoid falling obstacles, such as spikes and traps, while collecting bananas scattered throughout the environment.
- The goal is to climb as high as possible and gather bananas to increase the score.
- The game’s difficulty gradually increases as time passes, with obstacles coming faster and in more challenging patterns.
- The game ends when the character collides with an obstacle.
